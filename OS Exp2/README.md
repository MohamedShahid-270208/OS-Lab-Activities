# Experiment 2

Illustrate UNIX Commands and Shell Programming

## UNIX Commands Covered

### System Information
```bash
uname -a
cat /etc/os-release
whoami
hostname
lscpu
df -h
```

### Basic UNIX Commands
```bash
date
cal
echo
pwd
who
mkdir
ls
cat
cp
mv
rm
wc
lp
pg
head
tail
more
grep
sort
```

### Pipe and Filter Commands
```bash
ls | wc -l
echo unix | tr "[a-z]" "[A-Z]"
```

### Communication Commands
```bash
mesg y
write
wall
mail
reply
```
